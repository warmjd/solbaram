# 솔바람 마을

친구끼리 하는 클래식 감성 모바일 RPG. 폰 브라우저에서 링크만 열면 됩니다. Claude 계정은 필요 없습니다.

## 구성
- `server.js` : 정적 파일 + 실시간 중계 서버 (Node 18 이상, 외부 패키지 없음)
- `public/index.html` : 게임 전체 (한 파일)
- `render.yaml` : Render 배포 설정 (선택)

## 내 컴퓨터에서 시험
1. Node.js 18 이상 설치
2. 이 폴더에서 `node server.js`
3. 브라우저에서 `http://localhost:3000` (창을 두 개 열면 혼자서 두 명 테스트 가능)
4. 같은 와이파이의 폰: `http://컴퓨터IP:3000`

## 친구와 하려면 인터넷에 올리기 (Render 무료 플랜 기준)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다.
2. render.com 가입 후 New > Web Service > 그 저장소 선택
3. Runtime: Node, Build Command: 비우거나 `echo ok`, Start Command: `node server.js`, Instance Type: Free
4. 배포가 끝나면 나오는 주소(`https://이름.onrender.com`)가 게임 링크입니다.

무료 플랜은 15분 동안 아무 접속이 없으면 잠들고, 다시 열 때 약 1분 걸립니다. 게임 중 실시간 통신은 접속 상태로 인정되어 켜진 채 유지됩니다. 매달 무료 사용 시간(750시간)이 있습니다.

## 방 코드
- 주소 뒤에 `?room=우리끼리`처럼 붙이면 그 방에서만 만납니다. 방 코드를 아는 사람은 누구나 들어올 수 있으니 길고 남이 모를 코드를 쓰세요. 예: `?room=sunny-wolf-7421`
- 한 방에 최대 6명입니다.

## 저장
캐릭터는 각자 폰 브라우저에 저장됩니다. 브라우저 데이터를 지우거나 다른 폰으로 옮기면 사라집니다. 상점의 "새 캐릭터로 시작"을 누르면 저장이 지워집니다.

## 그림 바꾸기
지금 그림은 코드로 그린 임시 도트입니다. 투명 배경 PNG 스프라이트를 준비해서 알려주시면 연결해 드립니다.
